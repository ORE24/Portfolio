# 🚀 AI Developer Portfolio

인공지능(AI) 모델링 및 데이터 분석 역량을 보여주기 위해 제작한 **개인 포트폴리오 웹사이트**입니다.
HTML, Tailwind CSS(CDN), Vanilla JavaScript를 사용하여 가볍고 빠른 싱글 페이지(Single Page)로 구성했습니다.

## 🔗 Live Demo
> **[포트폴리오 사이트 바로가기](https://pf26.netlify.app/)** > *(위 링크를 클릭하면 배포된 사이트로 이동합니다)*

<br>

## 🛠 Tech Stack

| Category | Technology |
| --- | --- |
| **Frontend** | HTML5, CSS3 |
| **Styling** | [Tailwind CSS](https://tailwindcss.com/) (CDN) |
| **Scripting** | Vanilla JavaScript (ES6+) |
| **Deployment** | [Netlify](https://www.netlify.com/) |
| **Fonts** | [Pretendard](https://github.com/orioncactus/pretendard) |

<br>

## ✨ Key Features

* **Responsive Design:** 모바일 및 데스크탑 환경에 최적화된 반응형 레이아웃
* **Minimalist UI:** 콘텐츠에 집중할 수 있는 깔끔한 디자인
* **Project Modals:** 상세 내용을 팝업(Modal) 형태로 제공하여 페이지 이동 없는 사용자 경험 제공
* **Fast Loading:** 별도의 번들링 과정 없이 CDN을 활용한 빠른 로딩 속도
